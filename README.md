# Grant Jones - Portfolio

A retro terminal-themed portfolio website built with React and deployed on GitHub Pages.

**Live Site:** [grantjones-526.github.io](https://grantjones-526.github.io)

## Features

- Retro terminal boot sequence animation
- Keyboard navigation (arrow keys + enter)
- Mobile responsive design
- Project showcase with GitHub integration
- Contact form

## Tech Stack

- React 19
- React Router DOM
- CSS3 with custom properties
- GitHub Pages

## Local Development

```bash
cd client
npm install
npm start
```

Runs on `http://localhost:3000`

## Deployment

```bash
cd client
npm run deploy
```

This builds the app and pushes to the `gh-pages` branch.
